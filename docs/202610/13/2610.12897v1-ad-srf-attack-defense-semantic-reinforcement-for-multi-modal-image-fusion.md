## 摘要
由于视觉质量与语义属性优化目标之间的固有冲突，现有的图像融合方法难以平衡这两者。为了应对这一挑战，我们提出了一种用于多模态图像融合的攻防语义增强框架，称为 AD-SRF。该框架通过解耦这两个方面的优化并在无损情况下将其重新集成，在不损害视觉质量的前提下，将丰富的语义属性注入融合图像中。首先，我们开发了一个基于 Transformer 的恢复式视觉融合网络，作为强大的视觉基准。通过配备跨模态检索模块和信息恢复-融合协同损失，它甚至能在退化条件下生成高可见度的融合图像。其次，我们引入了一种攻防博弈机制，以增强融合图像的语义属性。攻击者学习损害下游分割的扰动模式，而防御者则从原始输入中恢复丢失的语义，并通过一个不可察觉的语义图将其重新整合到融合图像中。通过迭代的对抗交互，该机制促使防御者不断增强融合图像的语义属性，在不损害视觉质量的前提下提升下游分割性能。大量实验表明，AD-SRF 在视觉质量和语义属性方面均实现了双赢的性能。代码已公开于 https://github.com/HaoZhang1018/AD-SRF。

## Abstract
Existing image fusion methods struggle to balance visual quality and semantic attributes due to the inherent conflict between their optimization objectives. To address this challenge, we propose an attack-defense semantic reinforcement framework for multi-modal image fusion, termed AD-SRF. By decoupling the optimization of these two aspects and then losslessly reintegrating them, this framework injects rich semantic attributes into the fused image without compromising its visual quality. First, we develop a transformer-based restorative visual fusion network as a strong visual baseline. Equipped with the cross-modal retrieval module and the information restoration-fusion collaborative loss, it produces highly visible fused images even under degraded conditions. Second, we introduce an attack-defense game mechanism to strengthen the semantic attributes of the fused images. The attacker learns perturbation patterns that impair downstream segmentation, whereas the defender restores missing semantics from the original inputs and reintegrates them into the fused image through an imperceptible semantic map. Through iterative adversarial interaction, this mechanism drives the defender to continually strengthen the fused image's semantic attributes, boosting downstream segmentation performance without compromising visual quality. Extensive experiments demonstrate that AD-SRF achieves a win-win performance in both visual quality and semantic attributes. The code is publicly available at https://github.com/HaoZhang1018/AD-SRF.
