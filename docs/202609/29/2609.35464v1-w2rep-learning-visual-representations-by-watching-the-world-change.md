## 摘要
图像捕捉的是某一瞬间的世界，而视频则揭示了世界如何变化。图像自监督学习通常从单一时刻学习空间结构，而视频方法通常从多帧联合计算的表征中学习时间关系。我们探讨了观察场景变化是否能在不牺牲视频表征能力的前提下，提升单张图像的特征质量。我们提出了 W2Rep，这是一个掩码特征预测框架，其中独立编码的源图像参与同一时刻或不同时刻的预测。预测器以可见的视频上下文、查询位置以及源图像与目标图像之间的时间间隔为条件。这赋予了跨帧目标两个互补的角色：图像路径学习在时间跨度内保持有效的特征，而视频路径则负责收集源图像中缺失的信息。在不同模型规模和下游任务中，W2Rep 在我们的对比协议下提升了冻结和微调后的识别性能，同时联合视频编码相比逐帧聚合提供了进一步的增益。受控实验表明，这些增益依赖于对源图像特征的直接更新，以及对视频上下文和时间位移的使用。总而言之，视频中的变化可以监督视觉编码器，使其表征在图像或视频粒度上均保持有效。代码已发布于 https://wenooi.github.io/W2Rep。

## Abstract
Images capture the world at one moment, whereas video reveals how it changes. Image self-supervision learns spatial structure from a single moment, while video methods commonly learn temporal relationships inside a representation computed jointly from several frames. We ask whether watching a scene change can instead improve features available from one image without sacrificing the ability to represent video. We introduce W2Rep, a masked feature-prediction framework in which an independently encoded source image participates in prediction at the same or another moment. The predictor is conditioned on visible video context, the queried location, and the signed time interval between source and target. This gives the cross-frame objective two complementary roles: the image path learns features that remain useful across time, while the video path must gather evidence that is missing from the source image. Across model scales and downstream tasks, W2Rep improves frozen and fine-tuned recognition under our comparison protocol, while joint video encoding provides further gains over frame-wise aggregation. Controlled experiments show that these gains depend on directly updating the source-image features and on using both video context and temporal displacement. Overall, change across a video can supervise a visual encoder whose representations remain useful at either image or video granularity.
