## 摘要
图像去模糊是计算机视觉中的一项基础任务，但现有方法主要针对特定场景。因此，这些模型在面对不同相机和图像内容时，去模糊性能会显著下降。这促使我们开发一种能够处理多种模糊模式的统一运动去模糊框架。为此，我们构建了一个多源数据集，并开发了一套数据剪枝与质量控制流程。随后，为了恢复不同场景下具有各种运动模糊核的模糊图像，我们提出了一种基于傅里叶卷积学习的统一运动去模糊框架。现有的去模糊网络通常依赖于像素级映射，忽略了模糊的卷积本质。因此，网络大多是在拟合图像内容本身，而非学习卷积过程，这使得处理多源模糊图像变得困难。我们不再依赖空间映射，而是在傅里叶空间中进行模糊自适应全局滤波器学习，从而避免了核估计中空间支持受限的问题。大量实验表明，我们的统一模型能够有效处理来自不同来源和场景的运动模糊，在域内和域外（OOD）基准测试中均取得了具有竞争力的性能。代码将发布于 github.com/DeepMed-Lab-ECNU/Single-Image-Deblur。

## Abstract
Image deblurring is a fundamental task in computer vision, yet existing methods mainly specialize in isolated scenarios. Consequently, the deblurring performance of these models drops significantly across scenarios with different cameras and image contents. This motivates the development of a unified motion deblurring framework that can handle diverse blur patterns. To this end, we construct a multi-source dataset and develop a data pruning and quality control pipeline. Then, to restore blur images with various motion blur kernels across different scenarios, we propose a unified motion deblurring framework via Fourier Convolution Learning. Existing deblurring networks usually rely on pixel-level mappings and overlook the convolutional nature of blur. Thus, the network mostly fits the image content itself rather than learning the convolution process, making it difficult to handle multi-source blur images. Instead of relying on spatial mapping, we perform blur-adaptive global filter learning in Fourier space, which avoids the limited spatial support of kernel estimation. Extensive experiments demonstrate that our unified model effectively handles motion blurs across diverse sources and scenes, achieving competitive performance across both in-domain and OOD benchmarks. Code will be released at github.com/DeepMed-Lab-ECNU/Single-Image-Deblur.
