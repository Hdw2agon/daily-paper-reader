## 摘要
多模态图像融合（MMIF）旨在将来自不同模态的互补信息整合为高质量的融合图像，并支持下游任务。近年来，特征分解通过将源图像分离为公共特征和模态特有特征，已成为一种重要的范式。然而，由于缺乏真实（GT）分解特征图，现有方法往往缺乏明确的监督。它们通常结合多种图像级指标作为损失函数，但这些指标本质上是不完整的，且由于每个像素都耦合了纹理、边缘和轮廓等属性，可能会产生冲突。为了解决这一问题，我们提出了一种一维信号级自监督特征分解范式。我们的核心见解是将特征分解从模糊的二维图像级监督重新表述为积分驱动的一维信号级优化问题。这种目标层面的重构利用一维信号形式来计算积分约束。分解器通过公共信号与原始信号之间的积分面积进行优化，从而实现了具有明确优化目标的更稳定优化过程。我们的模型遵循两阶段自监督学习（SSL）框架：第一阶段设计了用于信号级积分驱动分解和图像级结构保持重建的双重预训练任务；第二阶段将特有特征与公共特征融合，以重建最终的融合图像。在代表性 MMIF 任务上的实验表明，该方法达到了最先进（SOTA）的性能。代码地址：github.com/Wangjiayu0512/SIDFusion。

## Abstract
Multimodal image fusion (MMIF) aims to integrate complementary information from different modalities into a high-quality fused image and support downstream tasks. Recently, feature decomposition has become an important paradigm by separating source images into common and modality-specific unique features. However, existing methods lack clear supervision because ground-truth (GT) decomposition feature maps are unavailable. They usually combine multiple image-level metrics as losses, which are inherently incomplete and may conflict since each pixel couples attributes such as texture, edge, and contour. To address this, we propose a 1D signal-level self-supervised feature decomposition paradigm. Our core insight is to reformulate feature decomposition from unclear 2D image-level supervision into an integral-driven 1D signal-level optimization problem. This objective-level reformulation uses the 1D signal form to compute the integral constraint. The decomposer is optimized by the integral area between common and original signals, enabling more stable optimization with a clear optimization objective. Our model follows a two-stage SSL framework. Stage I designs dual pretext tasks for integral-driven decomposition at the signal level and structure-preserving reconstruction at the image level. Stage II fuses unique features and combines them with common features to reconstruct the fused image. Experiments on representative MMIF tasks show state-of-the-art (SOTA) performance.
